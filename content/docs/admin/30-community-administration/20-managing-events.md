Managing Events is used to publish, update, and retire community event entries.
Clear event records improve participation and reduce confusion.

## Event lifecycle

1. Create a new event with title, timing, and context.
2. Review content for clarity and relevance.
3. Publish and verify visibility on resident pages.
4. Update or archive when details change.

## Quality checklist

- clear title and schedule information
- accurate location or participation guidance
- no duplicate active events for the same activity
