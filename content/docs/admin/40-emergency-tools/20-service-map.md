Service Map provides situational awareness for emergency planning and coordinated response.
It combines selected properties with map layers and operational detail popups.

## Typical usage

1. Select street or property targets.
2. Show selected data on the map.
3. Inspect boundaries, points, and captured feature layers.
4. Clear selections and repeat for the next scenario.

## What to validate

- selected targets appear as expected
- popup details are complete for active operations
- no-mappable-data cases are clearly identified

## Best practices

- keep map focus on the active response area
- use shared selection links carefully and confirm target list before distribution
- regenerate report outputs when selections change
