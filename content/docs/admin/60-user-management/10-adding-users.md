Adding Users is used to onboard new people into SOC with the correct initial access.
This workflow should balance fast onboarding with role and data-scope safety.

## When to use this workflow

- onboarding a new resident or operator
- creating admin-managed user records after approval steps
- preparing accounts for coordinator or admin assignment

## Standard workflow

1. Confirm the user is approved for onboarding.
2. Create or register the user account details.
3. Assign the minimum role needed for current responsibilities.
4. Verify first sign-in and route access behavior.

## Required checks

- email and identity details are correct
- no duplicate account exists for the same person
- role assignment matches intended scope

## Common issues

- user cannot see expected menu items: role/permission mismatch
- user sees too much: role assignment too broad
- user not appearing in downstream admin lists: refresh and verify account state
