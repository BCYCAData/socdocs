The admin dashboard is the primary entry point for governance, coordination, and operational tasks.
It provides navigation into community, site, emergency, and user-management functions.

## What you can access

- community administration sections
- site-level data and configuration areas
- emergency operations views and reports
- user-management workflows

## Recommended daily workflow

1. Review pending tasks and updates.
2. Open the relevant admin section for action.
3. Complete changes and confirm save or publish outcomes.
4. Recheck key pages for expected visibility and access.

## Troubleshooting tips

- missing dashboard sections usually indicate permission scope mismatch
- recent role changes may require re-authentication before menus update
