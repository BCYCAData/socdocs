Emergency reports generate printable or shareable outputs for property and street-level coordination.
Use reports when you need a structured snapshot for operational decision-making.

## Common report types

- street-focused reports covering grouped properties
- property-focused reports for selected addresses

## Workflow

1. Open Emergency Reports from admin navigation.
2. Select the report type and target scope.
3. Generate and review output details.
4. Export or share using approved operational channels.

## Quality checks

- verify property list matches selection
- verify key fields are present before distribution
- regenerate if source selections changed
