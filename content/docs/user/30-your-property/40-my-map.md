My Map lets you view property context and edit map features for assets, hazards, and operational details.
Feature editing is template-based, so you should select the correct layer type before drawing.

## What you can do

- view property boundary and surrounding context
- add point, line, or area features
- edit existing feature attributes
- delete incorrect features

## Basic editing flow

1. Open My Map for a property.
2. Choose the feature layer/template you want to edit.
3. Draw or select a feature.
4. Complete required fields in the side panel.
5. Save and confirm the update appears on the map.

## Important behavior

- drawing tools apply only to the selected feature type
- required fields must be completed before save
- validation warnings may appear for boundary or geometry quality issues
- saved changes should persist after refresh

## Common troubleshooting

- Cannot edit expected feature: verify the selected layer type.
- Save blocked: complete missing required fields.
- Unexpected geometry result: retry with cleaner vertices and check boundary alignment.
