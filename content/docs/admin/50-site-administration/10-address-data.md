Address Data administration maintains the address records that support resident onboarding, mapping, and reporting.
Reliable address data is critical for property linkage and operational views.

## Core responsibilities

- review address records and matching outcomes
- correct or add custom address entries when needed
- verify map and profile linkage behavior after updates

## Workflow

1. Open Address Data tools.
2. Review current address entries and unresolved cases.
3. Apply corrections or additions.
4. Validate downstream behavior in map/profile flows.

## Validation checks

- address resolves correctly in lookup flow
- linked property context appears on relevant pages
- no duplicate conflicting entries
