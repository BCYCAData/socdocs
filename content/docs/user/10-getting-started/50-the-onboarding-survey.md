The onboarding survey collects your baseline profile and property information.
SOC uses these answers to configure your starting view and completion progress.

## How onboarding works

- The survey is split into sections.
- Required fields are marked and must be completed before final completion.
- Progress updates as you save each section.

## Recommended flow

1. Start with personal details.
2. Save each section before moving to the next.
3. Return to incomplete required fields shown in progress indicators.
4. Complete the final section and submit.

## If you cannot finish in one session

- Save your progress in each section.
- Return later to complete remaining required answers.
