Profile Requirements controls which onboarding and profile fields are mandatory for completion.
This helps maintain reliable resident data quality across the platform.

## What this controls

- which questions are required
- how completion status is calculated
- what users must finish before profile completion is considered current

## Update workflow

1. Review current requirement settings.
2. Adjust required field flags as needed.
3. Verify impact on profile completion indicators.
4. Communicate significant requirement changes to relevant teams.

## Validation considerations

- avoid sudden requirement changes without rollout context
- ensure required fields are understandable to end users
- test affected onboarding paths after updates
