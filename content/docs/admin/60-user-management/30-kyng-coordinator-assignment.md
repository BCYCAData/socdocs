KYNG Coordinator Assignment links eligible users to specific KYNG areas for scoped coordinator operations.
Assignments determine both route access and area visibility.

## Assignment workflow

1. Confirm the target user is eligible for coordinator duties.
2. Select the KYNG area assignment.
3. Save the assignment and verify success feedback.
4. Have the user sign in again to refresh claims if needed.

## Updating or ending assignments

- update assignment when area responsibility changes
- end assignment when coordinator duties cease
- verify coordinator menu visibility changes on next sign-in

## Conflict handling

- avoid duplicate overlapping assignments without intent
- verify area ownership before reassignment
- escalate unresolved scope conflicts to site administrators

## Validation checks

- assigned user can access only intended coordinator routes
- non-assigned areas remain blocked
- area map and user-admin views reflect assignment scope
