Roles and Permissions defines who can access which route families and operational actions.
Use this area to enforce least-privilege access and maintain governance controls.

## What to manage

- user-to-role assignments
- role-to-permission mappings
- targeted access for feature-specific administration

## Assignment workflow

1. Review current role and permission state.
2. Apply required access changes.
3. Verify route and menu access behavior with a test account.
4. Re-authenticate users if claims refresh is required.

## Governance checks

- avoid broad grants when narrower scopes are sufficient
- document high-impact permission changes
- periodically audit role assignments for drift
