Messages administration controls platform notices shown to users in operational contexts.
Use this area for timely, clear communication aligned to audience and scope.

## Message workflow

1. Create or edit message content.
2. Set visibility and audience scope.
3. Publish and verify message display.
4. Update or retire outdated messages.

## Good practices

- keep message intent clear and concise
- include timing context when action is needed
- remove stale notices promptly
