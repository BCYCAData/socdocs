The SOC documentation site is now live as a single consolidated docs experience.
It brings user, administrator, technical, and project guidance together in one public site.

## What has launched

- one documentation site with four guide sections
- static, prerendered public delivery
- search-enabled navigation across current pages

## Who this is for

- residents using SOC features
- coordinators and administrators supporting local operations
- maintainers and contributors who need technical references
- community and project stakeholders seeking public project context

## Why this matters

The launch replaces fragmented guide delivery with a clearer, easier-to-maintain structure.
It also provides a stable foundation for iterative content updates and deeper in-app help linking.

## What comes next

- continued content completion and verification for project-history detail pages
- screenshot and workflow enrichment for user and admin guides
- tighter integration between contextual in-app help and docs deep links
